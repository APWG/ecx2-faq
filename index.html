This document captures a number of commonly asked questions about the APWG eCrime eXchange (eCX) and its operations.

  1. How does APWG get their data

    All of our phishing URIs, cryptocurrency addresses, and malicious domains are supplied by our member organizations. The APWG does not operate any sensors or gatherers on its own, with one exception; the reportphishing module. The reportphishing feed is a public-facing emailbox that receives reports from non-members and the public at large. The reportphishing module is processed internally and appropriate data introduced into the other modules.

  2. Are all data records the same?

    No. Every record contains a representation of how confident the person who submitted that data is of its maliciousness. The confidence field is one of four values:

    • 100 CF = inspection/confirmation by an APWG member reporter, submitting data under terms set out in the APWG Data Sharing Agreement.

    • 90 CF = inspection/discovery by Artificial Intelligence or Machine Learning systems directly curated by an APWG member submitter, under terms set out in the APWG Data Sharing Agreement. Users are encouraged to verify records at this level before just indiscriminately blocking them.

    • 50 CF = Machine data-capture or third-party volunteered report without confirmation by APWG member personnel or by a member-curated AI/ML. The assumption is that the record has a 50/50 chance of being accurate, therefore requiring investigation before use.

    • >0 CF = False positive. The data was reported a phish or malicious site but further investigation decided that it is not.

    Users should select the appropriate confidence value when inserting data records and evaluate the returned value before using the data.

    NOTE: We try to never remove data from the eCX, just remark its confidence and status fields, as removing a record does not infer to other users whether this record is no longer malicious or active.

  3. How do I mark a data record as a false positive?

    False positives have a confidence value of 0 (zero). Find the record you wish to modify, double click it, change the confidence to 0, and click update.

  4. I cannot find the data I am looking for.

    There are many different scenarios for this answer.

    1. First, people blame the APWG for everything. It is possible that we do not have the bad data in our database. If you are sure we have the data send a message to support and we will investigate.
    2. Second, the most common issue is that the database searcher is confused. We have seen this happen with multiple "."" or "-"" in a domain name or URI. For a URI, start with the http:// or https:// adding the domain name a little slower as the searching function researches on every key stroke.
    3. Also, we have experienced searching failures when your local web browser has been "updated" but not "restarted". (Really.)

  5. Can I get another user invited to the eCX?

    Yes, membership comes with multiple users. Request an invitation via the our admin or support addresses. Likewise, please advise if one of your users has left your operation team or employment so we can reduce the likelihood of an inactive account being breached.
